Skyfold Studio is a free, open-source 3D world builder built with Rust and Bevy.

Download **Skyfold-Studio-macOS.dmg**, open it, and drag Skyfold Studio into Applications. This preview is for Apple silicon Macs. The app is Developer ID signed and the DMG is notarized by Apple.

**Coming from 0.1.2 or earlier?** Download this version once. From now on, Skyfold Studio updates itself.

## New

- **Updates arrive by themselves.** Skyfold Studio checks for new versions once a day, or any time from File › Check for Updates…. When one is ready, it shows what's new and offers to install it and restart. Your open world is saved first.
- **Search finds every setting.** Search (⌘K) now finds the sliders, switches and sections in every panel, not just tabs and tools. Type "haze", "thunder" or "spawns" to see where each one lives, such as Atmosphere › Weather › Rain › Thunder. Pick a result to jump there: the right tab and tool open and the setting is highlighted.

## Improved

- **Easier-to-read panels.** The side panels, inspector, tool rail and top bar are a little more solid, so text stays clear over bright sand, snow and sky.

Worlds, imports and settings stay in `~/Library/Application Support/Skyfold Studio`.
